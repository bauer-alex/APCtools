# Internal helper to tilt the x-axis for the hexamap plot

Internal helper function to be called in
[`plot_APChexamap`](plot_APChexamap.md), to tilt the x-axis for the
hexamap plot.

## Usage

``` r
compute_xCoordinate(period_vec)
```

## Arguments

- period_vec:

  Numeric vector of period values.
